# Mayor's Decision in Disaster Recovery

An interactive website shows how Mayor's political decision can reduce financial losses and help citizens recover from a disaster.

**Live site:** https://cindyxi0722.github.io/Climaterisk-Mayor-decision/

The website describes one imaginary mid-sized U.S. river city with 4,000 homes in its floodplain. Default values come from:

- NOAA Climate.gov: heavy-rain trends
- FEMA: percent-damage guidance
- National Institute of Building Sciences, *Mitigation Saves*: about $7 saved per $1 spent on riverine flood buyouts

Created by: Cindy Xi, Jordan Scott, David Farrior
